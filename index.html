生词筛查

手机和电脑用同一个 GitHub 令牌，进度就会自动同步。令牌只需要 gist 权限，只保存在这台设备上。

  1. 打开 GitHub 新建令牌，有效期选 No expiration，只勾 gist，点 Generate token。
  2. 复制生成的令牌（ghp_ 开头），粘贴到下面，点「连接」。另一台设备粘贴同一个令牌即可。
导入旧进度 · 备份

在旧版网页「怎么用」底部点「导出全部进度」，复制出来的内容粘贴到这里，点「导入」。只需要在一台设备上导入一次，另一台会自动同步过去。

怎么用

你的欧路生词本、英式词库和词频约第 4,500–7,500 名的词，已经全部打乱，每组 100 个。点一下是认识，点两下是不确定，点三下恢复。提交后马上出现下一组，刚才那组的认识、待定和生词都进「中转站」，可以连续筛好几组再一起处理：待定的点「认识」或「生词」，认识的点「已掌握」或「移到生词本」，生词看过后点「看过了」。中转站有没处理的词时，tab 上会有红色数字。「生词本」顶部可以切换：生词列表（Today / All）、卡片复习（每天安排复习和新词）、批量学习（100 个一页的表格自测）。每个词都有英式音标和常用搭配，点喇叭听英式发音；点「记忆」展开记忆技巧：一个核心画面串起各个意思，碰巧同形的意思单独标出。「已认识」放你标过认识的词；顶部搜索栏可以查任何一个词在哪一类。
